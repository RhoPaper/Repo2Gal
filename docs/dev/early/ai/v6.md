# 📘 项目文档：Repo2Gal

**Repo2Gal** 是一款将开源项目代码库、技术文档与 Git 提交历史，自动化转化为交互式二次元视觉小说（Galgame）的轻量级转换工具。

项目旨在通过大语言模型（LLM）实现“硬核技术语义”与“二次元剧本演绎”的双轨重构，让开发者能够以兼具趣味性与沉浸感的方式，快速理解复杂的技术架构与演进历史。

---

## 🌟 核心功能

### 1. 代码库上下文语义提取

* **多源数据解析**：自动扫描并抽取代码仓库的目录结构、`README` 说明、核心配置、Git 提交记录以及测试用例。
* **技术特征人格化**：基于代码体量、依赖关系、测试覆盖率等维度，自动推导并生成符合二次元设定的角色性格与背景基调。

### 2. 双轨二次元剧本生成

* **技术术语原样保护**：在保持二次元剧情张力与角色对话萌点的同时，通过强约束机制原封不动保留核心 API、架构名称与英文术语。
* **多模态剧情渲染**：支持生成“演进历史战役”（如主线版本重写）与“架构交互导览”（如组件精灵对话）等多种剧本风格。

### 3. 剧本 DSL 解析与编译

* **文本指令转化**：将 LLM 输出的结构化 Markdown 剧本转换为视觉小说引擎可执行的标准指令流。
* **表情与立绘自动绑定**：识别对话中的情感标签（如：`傲娇`、`严肃`），自动映射并触发对应的角色立绘动作与表情切换。
* **交互分支映射**：自动将技术路径选择（如：不同架构方案选型）编译为剧本的交互选项与跳转分支。

### 4. 交互式视觉小说渲染与预览

* **音画同步渲染**：提供完整的二次元视觉小说呈现，包含场景切换、背景音乐播放、立绘平移及对话框打字机效果。
* **技术词条即时标注**：支持在剧本播放过程中高亮技术关键词，点击即可弹窗查看技术概念的准确解释。

## 🛠️ 使用的技术

| 模块分类 | 技术选型 | 功能说明 |
| --- | --- | --- |
| **核心处理管线** | Python 3.11+ | 负责数据提取流水线调度、大模型驱动封装及 DSL 解析编译 |
| **大语言模型引擎** | DeepSeek API / Gemini API | 负责代码语义抽象、二次元修辞转化与 Markdown 剧本创作 |
| **视觉小说渲染引擎** | WebGAL | 基于 Web 技术的现代轻量级 Galgame 渲染引擎，负责最终剧本呈现 |
| **控制台与预览界面** | Vue 3 + Tailwind CSS | 提供可视化控制台，用于仓库接入、生成参数配置与资源预览 |
| **数据校验与约束** | Pydantic / JSON Schema | 负责上下文提取数据结构约束与 LLM 生成文本的格式校验 |
