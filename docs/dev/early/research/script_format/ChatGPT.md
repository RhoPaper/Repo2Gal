# GAL游戏剧本：《Vue 的诞生：尤雨溪与响应式魔法的十年战争》

**类型：** 科技 × 创业 × 人物传记 × 视觉小说
**风格：** 日式青春群像剧 / 开发者冒险物语
**主题：** “一个人的实验，如何成为千万开发者的日常。”

> 注：剧情基于真实历史改编，部分对白和心理描写为艺术创作。Vue.js 由尤雨溪（Evan You）于 2014 年创建，最初是个人副项目，之后发展为社区驱动的开源框架。([Vue.js][1])

# 第一章：一颗种子（2013-2014）

## Scene 1：没有人知道的 Git Commit

【画面】

GitHub。

一个不起眼的仓库。

---

**旁白：**

> 最开始，它甚至不叫 Vue。

> 它只是一个实验。

> 一个关于“如何让界面自动更新”的小想法。

---

【代码】

```javascript
data.message = "Hello"
```

---

【页面】

文字自动变化。

---

**尤雨溪：**

“如果数据变化……”

“视图也能跟着变化。”

“那开发者是不是就不用手动操作 DOM？”

---

【出现魔法效果】

数据 → 魔法阵 → 页面

---

**旁白：**

> 这就是响应式。

> 一种后来影响整个前端世界的思想。

---

# 第五章：响应式魔法的战争（Vue 3）

## Scene 6：新的魔法体系

【时间】

2019-2020

---

【黑色背景】

标题：

```
Vue 3
```

---

**旁白：**

> 这是 Vue 历史上最大的一次改变。

---

新的力量：

```
Composition API
```

---

**开发者：**

“等等？”

“以前按照 data、methods 分类。”

“现在按照功能组合？”

---

**尤雨溪：**

“因为真实世界里的代码……”

“不是按照 API 分类的。”

---

【代码】

```javascript
const count = ref(0)

function increment(){
    count.value++
}
```

---

**旁白：**

> Composition API 让 Vue 更适合大型应用，也改善了 TypeScript 支持。([Vue.js][2])
